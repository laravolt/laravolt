## 2024-05-11 - Optimized Permission Check
**Learning:** Laravolt's `HasRoleAndPermission` and `Role` models do dynamic query checks or `contains` lookups when `hasPermission` is called. Since permissions are eager-loaded, doing a `contains` operation manually can bypass `app(config(...))` overhead and Model instantiation.
**Action:** Overrode `_hasPermission` in models to utilize eager-loaded relations properly.

## 2025-01-28 - Optimizing N+1 Database Queries using whereIn and memory mappings
**Learning:** `syncPermission` iterated over all registered permissions, executing an individual `firstOrNew()` SELECT query inside the loop to determine whether to save them. The use of `$this->permissions() + ['*']` was also failing because the array union operator drops elements when the left array already contains numerical indices. Emulating case-insensitive database matching via `keyBy(fn ($item) => strtolower($item->name))` is a highly effective way to do memory lookups and prevent duplicating records without executing repeated queries.
**Action:** When updating or saving numerous records in a loop based on string attributes, always batch-fetch the existing records beforehand using `whereIn`, map them to memory using `strtolower` to bypass strict array casing issues, and process via memory lookups inside the loop while leaving a fallback to `firstOrCreate()` for safety. Avoid the array union (`+`) for numerical arrays entirely and use `array_merge` or manual assignment (`$arr[] =`) to prevent dropping elements.
